────────── 以下为填写说明，发送前可整段删除 ──────────
· 输入类型与输入路径二者只提供一个：图片目录会递归扫描；物品清单是每行一个物品名的 .txt 文件。
· 图片目录任务中，源图文件名（不含扩展名）必须就是要提取的物品名，例如「红色马克杯.png」；不要用「IMG_0042.png」「截图1.png」等无语义文件名。
· Prompt 仍是必填项：候选内容只是参考/可复制内容，不会被当作默认值自动执行；留空或不改动 ❓ 待填写都视为未提供。
· Prompt 必须由你确认最终内容。本 Skill 不会替你补写、拼接、改写，也不会自动套用其他模板或目录旁文本。
· Prompt 可用两个占位符：{{物品名称}} 会逐项替换为文件名或清单条目；{{输出规格}} 会替换为最终尺寸说明。
· 选填项若为多值：第一个值即默认值。保留要用的一项、删掉其余；整行不改则按第一个值执行。
· 填了风格参考图 = 风格迁移（图片目录）或参考图文生图（物品清单）；填「无」= 图生图或纯文生图。参考图全批次共用一张。
· Provider 选 openai 时只支持纯文生图，带源图或参考图会在请求前被拒绝。
· 「banana 2」自动走 Venus 的 nano-banana-2；「chatgpt image 2」自动走 gpt-image-2。
· 远端分辨率只是生成质量提示；最终尺寸是本地 PNG 像素规格，会按比例缩放并居中补边，不拉伸。
· 更多 Prompt 写法示例见本 skill 的 prompts/prompt template.txt。
· 发回后会先跑 --dry-run，供你核对任务类型、条目数、输出目录和替换后的 Prompt 预览，确认无误后才会真实生成（会消耗 Provider 额度）。
