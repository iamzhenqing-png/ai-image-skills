# 首次使用者预设 Prompt

> 复制下方模板，填完所有带 `*` 的项目后发送给 AI。数值项必须显式给出；本文件末尾可持续补充已验证的真实案例。

```markdown
请使用“视觉大小归一化”处理一批本地素材图片，并在 Pass1 预演完成后暂停，等我确认再生成成品。

1. *输入目录：`/path/to/input`
2. 输出目录：`/path/to/output`（不填则在输入目录同级创建 `output/`）
3. 是否递归扫描子目录：是 / 否
4. *输出画布尺寸：`宽x高` 像素，例如 `800x800`
5. *安全边距：像素值，支持 CSS 简写，例如 `64`、`64 72`、`64 72 80 72`
6. *目标占比（`target-fill`）：`0~1` 之间的小数，例如 `0.82`
7. *过渡陡峭度（`transition-steepness`）：例如 `0.8`
8. *最大放大倍率（`max-upscale`）：例如 `1.0`
   - `1.0`：不放大，优先保护画质
   - 大于 `1.0`：允许放大；请确认原始分辨率足够
9. 图片背景：真实透明 PNG / 不透明图片 / 混合
10. 需要统一大小的主体是什么：例如“整件饰品”“人物全身”“餐盘（不含白色画布留白）”

处理要求：
- 保留原图背景，不做抠图、去背景或边缘清理。
- 对不透明图片，请直接读取原图，识别第 10 项描述的主体，并生成 `ai_bboxes.json`；无法可靠识别时填 `null`，不要猜测外框。
- Pass1 输出 `report.json`、`contact-sheet.png` 和带外框标记的预览：橙色框代表 AI 外框，绿色框代表 alpha 自动识别外框。
- Pass1 完成后暂停，等我确认；不要直接执行 Pass2。
```

## 首轮参数提示

`target-fill`、`transition-steepness` 与 `max-upscale` 目前是**未经真实素材校准的起始建议**，不是固定预设。首次建议使用：

- `target-fill`：`0.82`
- `transition-steepness`：`0.8`
- `max-upscale`：`1.0`

Pass1 优先检查外框是否正确、主体是否居中以及是否有 `quality_limit`；大小是否统一以 `report.json` 的数字为准。
