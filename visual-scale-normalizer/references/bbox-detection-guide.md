# 无 alpha 图片主体外框识别指引

JPG、alpha 全不透明 PNG 等图片没有可用透明边界。由 CodeBuddy 直接读取原图，为这些图片输出 `ai_bboxes.json`；脚本不调用视觉模型，也不猜测外框。

## 输出格式

```json
[
  {"name": "product-a.jpg", "bbox": [0.12, 0.08, 0.89, 0.92]},
  {"name": "product-b.jpg", "bbox": null}
]
```

- `name` 必须与 `manifest.json` 中的 `name` 完全一致；递归扫描时使用相对路径，例如 `set-a/product-a.jpg`。
- `bbox` 为 `[x1, y1, x2, y2]`，均为 0 到 1 的相对坐标；左上角为 `(0, 0)`，右下角为 `(1, 1)`。
- 确实不能识别主体时填 `null`。不要编造一个框，预演会把该项如实标记为失败。

## 框选标准

1. 识别画面中面积最大、视觉最突出、需要统一大小的主体。
2. 只框主体真实外接矩形，不含背景留白、阴影扩散、文字角标、边框或装饰性画布。
3. 主体贴边或被原图截断时，仍按实际可见边缘框选；不要为了制造留白而缩小外框。
4. 细长延伸部分（发梢、把手、长链、工具杆、翅膀等）必须包含在框内，宁可稍大，不要截断。
5. 图片里不存在明确主体、多个对象无法判断主次或画面严重模糊时填 `null`。

## 不要做的事

- 不要依据最终画布尺寸、边距或目标占比主动收缩/放大 bbox；这些都由几何层处理。
- 不要使用背景分割、传统阈值或 GrabCut 代替人工/多模态识别；复杂背景下这类方法不能可靠反映主体外框。
- 不要为了让联系表“看起来齐”而篡改外框。大小统一以数字报告为准，联系表用于发现识别和质量问题。
