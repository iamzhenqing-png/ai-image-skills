# 🎨 批量风格迁移（Batch Style Transfer）

> **用途**：批量对文件夹中的图片进行 AI 风格迁移，自动提取文件名填充 prompt 模板中的 `{{物品名称}}` 占位符。

## ⚙️ 前置准备：配置 API

本 Skill **内置**了生图 API 调用引擎（`scripts/api_image.py`），**只需下载本 skill 即可使用，无需再单独安装 api-image / 多模态内容生成 skill**。首次使用需要先配置 API 信息。

请在 CodeBuddy 工作区的 `TOOLS.md` 中添加以下内容（或让智能体帮你添加）：

```markdown
### API Image
- API Key: 你的 API 密钥
- Base URL: 你的中转站请求地址（例如 https://api.example.com/v1）
- Model: 模型名称（根据你的中转站命名填写，例如 gemini-2.5-flash-image）
- API Type: gemini  # 可选值: gemini / google / openai / venus
```

配置完成后，可先运行检查命令验证（脚本路径为本 skill 目录下的 `scripts/api_image.py`）：

```bash
python3 scripts/api_image.py check
```

> 💡 **建议**：风格迁移任务优先使用 `API Type: gemini` 或 `venus`（公司内部中转），二者均原生支持参考图输入；其他模型只能以文字描述方式生成，效果会打折扣。

## ✨ 核心特性

| 特性 | 说明 |
|------|------|
| 📁 **批量扫描** | 自动扫描指定文件夹，支持 `.jpg` / `.jpeg` / `.png` / `.webp` |
| 🔖 **文件名提取** | 自动去掉后缀，将物品名称填入 `{{物品名称}}` |
| 🎯 **通用参考图** | 一张参考图应用于所有源图 |
| 📝 **Prompt 模板** | 内置模板库 + 自定义文件 + 对话临时指定（**对话优先**） |
| 🤖 **多模型支持** | Gemini / GPT-Image / Banana / DALL-E（通过 API 调用） |
| 📂 **输出管理** | 在源图文件夹下自动创建 `output/` 目录 |

## 🚀 使用方式

### 基本用法

告诉智能体以下信息即可开始：

```
源图文件夹: /path/to/source/images/
参考图: /path/to/reference.png
Prompt: 将图中的{{物品名称}}风格迁移成扁平贴纸风格...
模型: gemini  （可选，默认 gemini）
```

### 高级选项

```
# 使用自定义 Prompt 模板文件
Prompt 文件: /path/to/my_template.txt

# 对话中临时覆盖（优先级最高）
Prompt: "把{{物品名称}}转成水彩手绘风，色彩柔和..."

# 指定输出分辨率
分辨率: 2K   （可选值: 512 / 1K / 2K / 4K）
```

## 📝 Prompt 模板说明

### 占位符

| 占位符 | 说明 | 示例 |
|--------|------|------|
| `{{物品名称}}` | 从源图文件名提取（去后缀） | `宝石耳环.jpg` → `宝石耳环` |

### Prompt 优先级（从高到低）

1. **对话中指定的 prompt** — 临时使用一次
2. **`prompts.txt` 文件** — 源图同目录下的预设文件
3. **内置默认模板** — 见下方"内置模板库"

### 内置模板库

以下模板已内置在 skill 中，可直接按编号选用，也可作为自定义参考：

---

#### 🏷️ 模板 T1：扁平贴纸风（最常用）

```
将图中的{{物品名称}}单独提取出来，风格迁移成参考图的扁平贴纸风格，
物体外轮廓是粗粗的白色描边，不要改变物体原本的造型和特征，
背景为纯深灰色便于后期抠图，画面比例 1:1，无多余元素。
```

**适用场景**：电商主图、商品素材、活动贴纸、图标设计

---

#### 🏷️ 模板 T2：矢量插画风

```
将图中的{{物品名称}}重新绘制成矢量插画风格，保留原始造型和比例，
使用平滑的色块填充，线条简洁干净，无渐变效果，
背景纯白，画面居中构图，1:1 比例。
```

**适用场景**：UI 图标、信息图表、品牌素材、印刷品

---

#### 🏷️ 模板 T3：水彩手绘风

```
将图中的{{物品名称}}用水彩手绘风格重新演绎，
保持物体原本的形态和特征，笔触自然柔和，
色彩通透有层次感，边缘略带晕染效果，
背景为浅米色纸张质感，画面比例 1:1。
```

**适用场景**：文创产品、包装设计、社交媒体配图、贺卡

---

#### 🏷️ 模板 T4：3D 立体渲染风

```
将图中的{{物品名称}}制作成 3D 渲染风格，
使用柔和的光照和材质，立体感强但不夸张，
采用 C4D / Blender 风格的渲染质感，
背景纯色（深灰），画面居中，1:1 比例。
```

**适用场景**：产品展示图、APP 启动页、广告素材

---

#### 🏷️ 模板 T5：像素艺术风

```
将图中的{{物品名称}}转换成像素艺术风格，
保持可识别性，使用 16-bit 复古游戏美术风格，
色彩鲜明对比度高，边缘清晰锐利，
背景透明感（纯深灰），1:1 比例。
```

**适用场景**：游戏素材、NFT 设计、潮流周边、复古主题

### 自定义 Prompt 文件格式

在源图同目录创建 `prompts.txt`，内容如下：

```text
# 这是注释行，会被忽略

将图中的{{物品名称}}单独提取出来，风格迁移成参考图的扁平贴纸风格，
物体外轮廓是粗粗的白色描边，不要改变物体原本的造型和特征，
背景为纯深灰色便于后期抠图，画面比例 1:1，无多余元素。
```

## 🛠️ 支持的生图模型

| 模型 | 关键字 | 参考图支持 | 分辨率 | 备注 |
|------|--------|-----------|--------|------|
| **Gemini** | `gemini` | ✅ 多张 | 512 / 1K / 2K / 4K | 推荐，原生支持参考图 |
| **Venus（公司内部中转）** | 任意，需配置 `API Type: venus` | ✅ 多张 | 由模型决定 | OpenAI Chat Completions 协议，适用于公司内部网关中转的 Gemini 等模型 |
| **GPT-Image-2** | `gpt-image` | ❌ | 1024 / 1536 | OpenAI 最新图像模型 |
| **Banana** | `banana` | ❌ | 标准 | 兼容 OpenAI 格式 |
| **DALL-E 3** | `dall-e` | ❌ | 1024 / 1792 | OpenAI 经典模型 |

> ⚠️ **提示**：只有 **Gemini** 和 **Venus** 原生支持传入参考图做风格迁移。其他模型会以文本描述方式提及参考图，效果可能打折扣。建议风格迁移任务优先使用 Gemini 或 Venus。

## ⚙️ 技术实现

- **核心脚本**: `scripts/batch_style_transfer.py` — 批量扫描、Prompt 模板渲染、任务调度
- **适配层**: `scripts/adapter.py` — 根据模型名选择调用协议，屏蔽底层 API 差异
- **API 调用引擎**: `scripts/api_image.py` — 内置，支持 Gemini / OpenAI / Venus 等协议，无需额外安装其他 skill
- **首次使用**: 需要配置 API Key 和模型参数（智能体会引导完成）

> 本 skill 为**自包含（self-contained）**设计：所有代码依赖均在 `scripts/` 目录下，其他使用者只需下载/安装本 skill 一个目录即可运行，无需再单独安装 api-image（多模态内容生成）skill。

- contract: v1（人工约定，非自动校验，仅供编排层/开发者对照）
