#   4. 如果对话中同时指定了 prompt，以对话中的为准

# ---- 选择下方一个模板使用（删除其他模板的 # 即可）----

# 【T1: 扁平贴纸风】推荐用于：电商主图、商品素材、活动贴纸
#将图中的{{物品名称}}单独提取出来，风格迁移成参考图的扁平贴纸风格，
#物体外轮廓是粗粗的白色描边，不要改变物体原本的造型和特征，
#背景为纯深灰色便于后期抠图，画面比例 1:1，无多余元素。

# 【T2: 矢量插画风】推荐用于：UI 图标、信息图表、品牌素材
#将图中的{{物品名称}}重新绘制成矢量插画风格，保留原始造型和比例，
#使用平滑的色块填充，线条简洁干净，无渐变效果，
#背景纯白，画面居中构图，1:1 比例。

# 【T3: 水彩手绘风】推荐用于：文创产品、包装设计、社交媒体配图
#将图中的{{物品名称}}用水彩手绘风格重新演绎，
#保持物体原本的形态和特征，笔触自然柔和，
#色彩通透有层次感，边缘略带晕染效果，
#背景为浅米色纸张质感，画面比例 1:1。

# 【T4: 3D 立体渲染风】推荐用于：产品展示图、APP 启动页、广告素材
#将图中的{{物品名称}}制作成 3D 渲染风格，
#使用柔和的光照和材质，立体感强但不夸张，
#采用 C4D / Blender 风格的渲染质感，
#背景纯色（深灰），画面居中，1:1 比例。
