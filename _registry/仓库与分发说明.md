# 仓库与分发说明

## 仓库怎么摆的

**仓库根目录 = `~/.codebuddy/skills/` 本身**，仓库名 `ai-image-skills`。

用**白名单 `.gitignore`** 只跟踪自己的东西：

```
被跟踪：README.md  CHANGELOG.md  .gitignore  _registry/
        bg-remover/  batch-image-resize/  batch-style-transfer/
        image-element-crop/  head-shoulder-crop/  lucky-item-style-transfer/
被忽略：其余全部（第三方 skill、TOOLS.md、台账、运行产物、缓存）
```

**为什么不把仓库放在别的目录**：那样会有两份文件——你日常改的那份（skills 目录）和仓库里那份。
每次改完都得记着同步一次，漏一次就发出去一个旧版本。放在原地就没有这个问题，改完直接 commit。

**代价（必须知道）**：这个目录现在是 git 仓库，但里面还有一堆「被忽略」的第三方 skill。
**永远不要在这里执行 `git clean -fdx`**，它会把被忽略的文件一起删掉，也就是把你所有第三方 skill 删掉。
除此之外的日常 git 操作（status / add / commit / push / pull）都是安全的。

## 旧的 5 个单独仓库

`bg-remover`、`batch-image-resize`、`batch-style-transfer`、`image-element-crop`、`head-shoulder-crop`
原先各自是一个 GitHub 仓库（`iamzhenqing-png` 名下）。改成套装仓后：

- 旧仓库**保留不动**（历史都在，随时能查），但**停止更新**。
- 本地那5 个 `.git` 目录已移到 `~/.codebuddy/skills-trash-<日期>/old-git-repos/`，
  是移动不是删除，需要时可以搬回来。

## 分发给同事

同事侧 4 条命令（README里有，让他的 AI 代跑即可）：

```bash
cd ~/.codebuddy/skills
git init -q
git remote add origin https://github.com/iamzhenqing-png/ai-image-skills.git
git fetch origin
git checkout -f -t origin/main
```

他原有的其他 skill 不会被动到（都在 `.gitignore` 里）。装完重启 CodeBuddy。

**永远整套分发**，不要让同事自己挑要装哪几个原子 skill —— skill 系统没有依赖自动安装，挑漏必断链。

## commit 纪律

| 前缀 | 含义 | 要做的事 |
|---|---|---|
| `feat(<skill>):` | 加功能，对外契约没变 | 直接提交 |
| `fix(<skill>):` | 修 bug，对外契约没变 | 直接提交 |
| `contract(<skill>)!:` | **对外契约变了** | 改契约 + 改 `CHANGELOG.md` + 改所有受影响工作流，**三样同一次 commit** |

改契约前先查 `_registry/工作流台账.md` 表二，看这个 skill 被哪些工作流依赖。

## 每次改完 skill 的收尾动作

```bash
python3 _registry/scripts/refresh_registry.py --write
```

台账本身不进仓库（含「已分发给谁」，是私人信息），只留在本地。
