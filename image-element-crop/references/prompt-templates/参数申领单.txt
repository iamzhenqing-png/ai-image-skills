请用 image-element-crop skill 批量裁剪图片，以下为我已确认的参数。

【必填】
输入来源：本地文件夹 / 企业微信文档表格 / 腾讯文档表格
输入路径或表格链接：❓ 待填写
目标尺寸（宽x高，可逗号分隔多个）：❓ 待填写
输出目录：❓ 待填写

【选填】
描述文件（仅本地文件夹模式）：无 / descriptions.json / descriptions.csv
图片列（仅表格模式）：自动识别 / 指定列序号
命名列（仅表格模式）：自动识别 / 指定列序号
描述列（仅表格模式）：自动识别最显著主体 / 指定列序号
行范围（仅表格模式）：全部行 / 指定范围，如 10-50
裁剪策略：contain（保留完整元素） / cover（铺满画面）
留白百分比：5 / 自定义数值
是否人工校验：默认关闭，直接出成品 / 开启（预览有风险条目时暂停等待确认）
同名文件处理：自动加序号 -2/-3 / 覆盖（--overwrite）

────────── 以下为填写说明，发送前可整段删除 ──────────
· 输入来源是必填项，请只保留一个值；本地文件夹会保留原文件名作为输出文件名，表格批量会按图片列/命名列取图。
· 输入路径或表格链接：本地文件夹填目录路径（相对或绝对均可）；企业微信文档表格填 `doc.weixin.qq.com` 链接；腾讯文档表格填 `docs.qq.com` 链接。
· 目标尺寸：可填多个尺寸，用逗号分隔，如 1200x900,800x800；每个尺寸各出一份成品，互不覆盖。
· 输出目录：成品图输出路径，支持含空格路径；产出分 `completed`、`attention`、`failed` 三级子目录。
· 本地文件夹模式：图片文件名会直接作为输出文件名，请确保文件名本身能描述图片内容（如“红色马克杯.jpg”），不要用 `IMG_0042.jpg` 等无语义命名；描述文件放在输入目录内，JSON 格式为 {"文件名.jpg": "描述文本", ...}，未匹配到描述的图片自动走主体识别。
· 企业微信文档表格：列序号从 1 开始；三列都留为自动识别时，图片列取本行第一个含图片的单元格，命名列取图片右侧第一个非空文本列，描述列取命名列右侧下一个非空文本列。正式任务建议明确填写图片列和命名列；命名列和描述列可以是同一列。腾讯文档表格：列索引从 0 开始，图片列和命名列必须明确填写，不支持自动识别；图片列必须是图片直链文本，单元格中真正插入的图片对象无法读取。有描述内容的行按描述文本只裁该局部元素，描述为空的行自动识别最显著主体；行范围为 1-based，含端点。
· 裁剪策略：contain 确保目标元素不被裁掉，放不下时优先平移，仍不够则补白；cover 铺满画面，允许裁掉部分留白甚至目标边缘，恒不越界。两种策略需分别跑两次，不支持一次输出两种。
· 留白百分比基于目标最长边计算。
· 人工校验开启后，仅当预览报告存在 attention/failed 条目才会暂停，等待你查看 `contact_sheet.jpg` 后再决定是否继续；正常情况仍直接出成品。
· 更多完整示例见同目录的 `table-batch.md` 与 `local-folder.md`。
