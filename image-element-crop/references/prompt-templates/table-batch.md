# 企业微信/腾讯文档表格批量模式

适用于：从企业微信文档或腾讯文档在线表格中，按图片列/命名列/可选描述列批量取图并裁剪。

## 可调参数速查表

| 参数项 | 说明 | 示例 |
|--------|------|------|
| `<表格链接>` | 企业微信文档或腾讯文档的表格 URL | `https://doc.weixin.qq.com/sheet/e3_...` |
| `<图片列>` | 图片所在列，列名或列字母均可 | `F`、`商品图`、`image` |
| `<命名列>` | 作为输出文件名的列 | `E`、`产品名`、`name` |
| `<描述列>` | 可选；用于定位局部元素的描述列，为空则自动识别最显著主体 | `E`、`描述`、`description` |
| `<行范围>` | 可选；只处理指定行（1-based，含端点），不填则处理全部 | `3-9`、`10-50` |
| `<尺寸>` | 目标宽高，可填多个尺寸用逗号分隔 | `1200x900`、`1200x900,800x800` |
| `<裁剪策略>` | `contain`（保留完整元素，默认）或 `cover`（铺满画面） | `contain` / `cover` |
| `<留白>` | 留白百分比，基于目标最长边，默认 5 | `5`、`10` |
| `<输出目录>` | 成品图输出路径，支持空格 | `/Users/xxx/Downloads/dish output` |

## 标准 Prompt

```markdown
请帮我用 image-element-crop skill 批量裁剪表格里的图片。

表格链接：<表格链接>

要求：
1. 图片在 <图片列>，<命名列> 作为输出文件名；
   <描述列处理说明>。
2. <行范围说明>。
3. 每张图同时输出 <尺寸> 尺寸。
4. 使用"<裁剪策略>"的策略，留白 <留白>%。
5. 裁剪前先生成叠框预览和报告，然后直接出成品，不用停下来等我确认。

输出到 <输出目录> 目录
```

## 完整示例

```markdown
请帮我用 image-element-crop skill 批量裁剪表格里的图片。

表格链接：https://doc.weixin.qq.com/sheet/e3_AAUA2wbtACgCNx0WLxqLLTVm6LnTf?scode=AJEAIQdfAAoc1HHecNAAUA2wbtACg&newPad=1&newPadType=clone&tab=BB08J2

要求：
1. 图片在 F 列，E 列的产品名作为输出文件名；E 列同时是裁剪目标描述：
   有描述的行按描述只裁那个局部元素，没描述的行自动识别画面最显著的主体。
2. 先只处理第 3 到 9 行。
3. 每张图同时输出 1200x900 和 800x800 两个尺寸。
4. 使用"cover（铺满画面）"的策略，留白 5%。
5. 裁剪前先生成叠框预览和报告，然后直接出成品，不用停下来等我确认。

输出到 /Users/wangzhenqing/Downloads/dish output 目录
```

> 注：描述列和命名列可以是同一列（如示例中的 E 列），也可以分开指定。
