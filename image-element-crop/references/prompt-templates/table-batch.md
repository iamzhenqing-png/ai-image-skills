# 企业微信/腾讯文档表格批量模式示例

以下仅为已填写的参考示例；缺少参数时请使用同目录的 `参数申领单.txt`。

```markdown
请用 image-element-crop skill 批量裁剪图片，以下为我已确认的参数。

【必填】
输入来源：企业微信或腾讯文档表格
输入路径或表格链接：https://doc.weixin.qq.com/sheet/<表格标识>
目标尺寸（宽x高，可逗号分隔多个）：1200x900,800x800
输出目录：./dish-output

【选填】
图片列（仅表格模式）：指定列序号 6
命名列（仅表格模式）：指定列序号 5
描述列（仅表格模式）：指定列序号 5
行范围（仅表格模式）：指定范围，如 3-9
裁剪策略：cover（铺满画面）
留白百分比：5
是否人工校验：默认关闭，直接出成品
同名文件处理：自动加序号 -2/-3
```

企业微信 Markdown 表格的列序号从 1 开始；腾讯文档 cells 数据的列索引从 0 开始，且必须明确指定图片列和命名列。
