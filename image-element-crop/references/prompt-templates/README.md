# Prompt 模板目录

本目录提供 `image-element-crop` skill 的标准调用 Prompt 模板，按使用场景分类。同事在处理类似项目时，可直接复制对应场景的模板，按 `<...>` 占位符填入自己的参数后发给 CodeBuddy。

## 文件说明

| 文件 | 场景 |
|------|------|
| `table-batch.md` | 企业微信/腾讯文档在线表格批量取图 |
| `local-folder.md` | 本地文件夹批量处理 |

## 使用步骤

1. 根据图片来源选择对应模板。
2. 复制"可调参数速查表"下方的"标准 Prompt"部分。
3. 将 `<...>` 占位符替换为实际值（列名、行号、尺寸、目录等）。
4. 直接发送给 CodeBuddy，无需记忆脚本参数名。

## 模板结构约定

每个模板包含三部分：

1. **可调参数速查表**：列出本场景所有可自定义项。
2. **标准 Prompt（占位符版）**：可直接复制，保留 `<...>` 占位符。
3. **完整示例**：一个真实可运行的参考文案。
