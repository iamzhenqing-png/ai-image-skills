# 参数申领单与参考示例

`参数申领单.txt` 是 `image-element-crop` 缺少必填参数时唯一的待填模板。收到后完整复制，填写带 `❓ 待填写` 的必填项；选填项保留要用的一个值即可。末尾说明区可在发送前整段删除。

| 文件 | 用途 |
|---|---|
| `参数申领单.txt` | 一次性填写所有参数；缺参时由 Skill 原样输出 |
| `table-batch.md` | 企业微信/腾讯文档表格批量裁剪的完整参考示例 |
| `local-folder.md` | 本地文件夹批量裁剪的完整参考示例 |

`table-batch.md` 和 `local-folder.md` 只供参考，不是执行输入；Skill 不会从中自动读取或代填参数。
