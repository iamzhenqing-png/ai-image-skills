# 本地文件夹批量模式

适用于：处理本地文件夹中的一组图片，保留原文件名作为输出文件名，可选 `descriptions.json`/`.csv` 指定局部元素。

## 可调参数速查表

| 参数项 | 说明 | 示例 |
|--------|------|------|
| `<输入目录>` | 本地图片文件夹路径，支持相对路径或绝对路径 | `./photos`、`/Users/xxx/Downloads/imgs` |
| `<描述文件>` | 可选；文件夹内的 `descriptions.json` 或 `.csv`，用于按描述定位局部元素 | `descriptions.json` |
| `<尺寸>` | 目标宽高，可填多个尺寸用逗号分隔 | `800x800`、`1200x900,800x800` |
| `<裁剪策略>` | `contain`（保留完整元素，默认）或 `cover`（铺满画面） | `contain` / `cover` |
| `<留白>` | 留白百分比，基于目标最长边，默认 5 | `5`、`10` |
| `<输出目录>` | 成品图输出路径 | `./output` |

## 标准 Prompt

```markdown
请帮我用 image-element-crop skill 批量裁剪本地图片。

输入目录：<输入目录>

要求：
1. 图片文件名作为输出文件名；<描述文件说明>。
2. 每张图同时输出 <尺寸> 尺寸。
3. 使用"<裁剪策略>"的策略，留白 <留白>%。
4. 裁剪前先生成叠框预览和报告，然后直接出成品，不用停下来等我确认。

输出到 <输出目录> 目录
```

## 完整示例

```markdown
请帮我用 image-element-crop skill 批量裁剪本地图片。

输入目录：./photos

要求：
1. 图片文件名作为输出文件名；如果文件夹里有 descriptions.json，按其中的描述定位局部元素，
   没有描述的图片自动识别画面最显著的主体。
2. 每张图同时输出 800x800 尺寸。
3. 使用"contain（保留完整元素）"的策略，留白 5%。
4. 裁剪前先生成叠框预览和报告，然后直接出成品，不用停下来等我确认。

输出到 ./output 目录
```

> 注：`descriptions.json` 格式为 `{"filename.jpg": "描述文本", ...}`，未匹配项自动走主体识别。
