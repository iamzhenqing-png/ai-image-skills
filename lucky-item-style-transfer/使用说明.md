# 幸运物风格迁移 · 使用说明（零基础版）

这是一套帮你**批量把幸运物截图转成统一风格贴纸、并裁成 900×900 透明 PNG 成品**的小工具。
全程不用写代码，主要就是"双击运行 + 按提示操作"。

---

## 一、它能帮你做什么

把这样一批杂乱截图 👉 自动变成统一风格、干净抠图、尺寸一致的成品：

```
准备-幸运物截图/龚俊/墨镜.png   ──┐
准备-幸运物截图/龚俊/草裙.png   ──┤  统一风格迁移 + 抠图 + 标准化
准备-幸运物截图/陈星旭/项链.png ──┘
                                  ↓
                输出-幸运物/  里一批 900×900 透明 PNG
```

两步全自动串起来：
1. **生成文案**：自动给每张图配好"风格迁移指令"（物品名自动取自文件名）
2. **AI 生图 + 自动下载 + 自动抠图**：用你自己的 **Gemini** 账号，按"原图 + 风格参考图"生成新图，**自动下载并抠图标准化**，成品直接出到 `输出-幸运物/`

> 🎉 全程无需手动保存图片！脚本会自动检测 Gemini 生成的图片并下载处理。

## 二、第一次使用（只需做一次）

### 准备 1：装好运行环境
**双击 `环境安装.command`**，等它自动装完（首次较慢，耐心等，别关窗口）。
看到"✅ 安装完成"就好了。

> ⚠️ 首次双击 `.command` 文件，Mac 可能提示"无法打开"。解决：
> **右键点该文件 → 选「打开」 → 再点「打开」** 即可（之后双击就行）。

### 准备 2：确认装了 Chrome
本工具用 **Google Chrome** 登录 Gemini。没装的话去 https://www.google.com/chrome/ 装一下。

### 准备 3：能上网访问 Gemini
需要你的电脑能正常打开 `gemini.google.com`（海外网络）。

## 三、平时怎么用（每次出图）

### 第 1 步：把素材放好
在你的项目文件夹里准备两个子文件夹：

```
你的项目文件夹/
├── 准备-幸运物截图/
│   ├── 新西兰-龚俊/        ← 按明星分文件夹
│   │   ├── 墨镜.png         ← 文件名就是物品名！会被直接读取
│   │   └── 草裙.png
│   └── 新西兰-陈星旭/
│       └── 项链.png
└── 准备-风格迁移参考图/
    └── 贴纸风格.jpg         ← 放 1 张你想要的风格参考图
```

> 💡 **重点**：截图文件名要是干净的物品名（如 `墨镜.png`），不要 `IMG_001.png` 这种。

### 第 2 步：双击 `一键运行.command`

然后按窗口提示操作：

| 提示 | 你要做的 |
|------|---------|
| 让你输入"项目目录" | 直接 Enter 用默认；或把你的项目文件夹**拖进窗口**再 Enter |
| 让你输入"关键字" | 想先试一个明星就输入如 `龚俊`；想全部跑就直接 Enter |
| Step1 跑完让你确认 prompt | 看一眼没问题就 Enter |
| Step2 打开 Chrome | **首次登录你的 Google 账号**（以后免登）；每张图脚本会自动上传双图+填指令+发送+下载+抠图，**全程自动** |
| 自动下载失败时的提示 | 偶尔自动下载失败，脚本会提示你手动保存一次，然后按 Enter 继续 |

### 第 3 步：取成品
全部跑完，成品在你项目文件夹的 **`输出-幸运物/`** 里，文件名格式如 `新西兰-龚俊-墨镜.png`。

## 四、想换风格 / 换提示词怎么办

| 想改什么 | 怎么做 | 重跑哪一步 |
|---------|--------|-----------|
| **整批换风格** | 替换 `准备-风格迁移参考图/` 里那张参考图 | 从 Step1 重跑 |
| **改风格指令措辞** | 改 `scripts/generate_prompts.py` 里的 `DEFAULT_TEMPLATE` 一段文字 | 从 Step1 重跑 |
| **只调某几张** | 改 `AI-幸运物待处理/prompts/` 里对应的 `.txt` | 只对那几张重跑 Step2（加 `--force`） |
| **重跑抠图（调参数）** | 单独运行 Step3 脚本，见下方说明 | 只跑 Step3 |

> 已经做好的图默认会**自动跳过**，不会浪费 Gemini 额度；只有你改动的部分才会重做。

### 单独重跑抠图（调整抠图参数）

如果成品抠图效果不理想，可以单独重跑 Step3 脚本调整参数：

```bash
# 提高色键去除力度（适合有残留绿边的情况）
python3 scripts/process_image.py --root "你的项目目录" --tolerance 90 --force

# 换 rembg 通用 AI 抠图（色键不干净时）
python3 scripts/process_image.py --root "你的项目目录" --method rembg --force
```

## 五、复用到新项目

这套工具和"素材文件夹"是分开的。换新项目时**不用改工具**：
- 双击 `一键运行.command`，在"项目目录"那一步把**新项目文件夹拖进去**即可。
- 新项目里同样准备好 `准备-幸运物截图/` 和 `准备-风格迁移参考图/` 两个子文件夹。

## 六、分发给同事

把整个 `lucky-item-style-transfer` 文件夹拷给同事即可。同事这边：
1. 双击 `环境安装.command` 装环境（一次）
2. 装好 Chrome
3. 双击 `一键运行.command` 开始用

> ⚠️ **每个人要用自己的 Gemini 账号登录一次**。登录信息只存在各自电脑上（`~/.lucky-item-gemini-profile`），互不影响，也更安全合规——这一步**无法代登**，需本人操作。

## 七、常见问题

**Q：双击 `.command` 弹"无法打开/来自身份不明开发者"？**
A：右键该文件 → 「打开」 → 再点「打开」。只需这样做一次。

**Q：Step2 自动下载失败怎么办？**
A：脚本会自动 fallback 到手动模式，提示你在 Chrome 里右键生成的图另存为到指定路径，按 Enter 继续即可。这种情况偶尔发生，通常是 Gemini 页面加载较慢导致。

**Q：抠图边缘不干净 / 有残留绿边？**
A：多数是生成图背景没成纯绿幕。可单独重跑 Step3 调整：
- 提高去除力度：`--tolerance 90`
- 或换方式：`--method rembg`（用通用 AI 抠图）

**Q：想只重做某一张？**
A：删掉它在 `输出-幸运物/` 里的结果，或用 `--force` 重跑 Step2。

**Q：跑到一半退出了，怎么续？**
A：再次双击 `一键运行.command` 即可，已完成的会自动跳过。

**Q：想保留 Gemini 原图（不抠图）怎么办？**
A：运行 Step2 时加 `--no-cutout` 参数，脚本会把 Gemini 生成的原图直接保存到 `输出-幸运物/`，不做抠图处理。

## 八、文件夹速查

```
lucky-item-style-transfer/      ← 工具本体（拷给同事就是它）
├── 环境安装.command            ← 首次双击装环境
├── 一键运行.command            ← 平时双击出图
├── 使用说明.md                 ← 本文件
├── SKILL.md                    ← 给 AI 看的流程说明
└── scripts/                    ← 脚本（一般不用动）
    ├── generate_prompts.py     （Step1 生成文案）
    ├── nano_banana2_transfer.py（Step2 Gemini 生图 + 自动下载 + 自动抠图）
    └── process_image.py        （Step3 单独抠图标准化，调参时用）

你的项目文件夹/                  ← 你的素材和成品
├── 准备-幸运物截图/             （放原始截图）
├── 准备-风格迁移参考图/          （放风格参考图）
├── AI-幸运物待处理/             （中间产物：文案 + 生成原图备份）
└── 输出-幸运物/                 ← 最终成品在这里（自动命名：新西兰-龚俊-墨镜.png）
```
