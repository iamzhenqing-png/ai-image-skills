# Prompt 模板示例

本文档提供常用的风格迁移 prompt 模板，用户可以直接选用或作为定制基础。

## 模板 A — 贴纸风（默认模板）

```
请参考风格图 `{reference_path}` 的画风，将源图 `{source_path}` 中的主体物品 **{lucky_name}** 转换成矢量风格的素材。要求：整个贴纸周围有一个干净的、白色的模切边；背景深灰色，便于抠图；主体清晰可辨，保留关键外形和代表性颜色；可爱手绘矢量插画质感；黑色粗描边；色彩鲜明；居中构图；正方形输出。
```

**适用场景**: 需要可爱、扁平化、类似贴纸的视觉效果。

## 模板 B — 精细矢量插画风

```
请参考风格图 `{reference_path}` 的画风，将源图 `{source_path}` 中的主体物品 **{lucky_name}** 转换成精细矢量插画。要求：保留物品的关键外形特征和标志性颜色；线条干净流畅；色彩饱和度高但不刺眼；有轻微的立体感（通过高光和阴影）；白色描边；透明背景；居中构图；无多余元素。
```

## 模板 C — 极简图标风

```
将源图 `{source_path}` 中的 **{lucky_name}** 简化为极简矢量图标。要求：只保留最核心的轮廓特征；单色或双色设计；粗线条（3-5px）；无渐变；正方形画布；透明背景。
```

## 变量说明

| 变量 | 来源 | 示例 |
|------|------|------|
| `{lucky_name}` | 截图文件名（去扩展名） | `耳环`、`水杯` |
| `{ip_name}` | 父目录名 | `新西兰-王玉雯` |
| `{source_path}` | 截图完整路径 | `/path/to/耳环.png` |
| `{reference_path}` | 参考图完整路径 | `/path/to/贴纸风格.jpg` |

## 定制指南

1. **保持变量不变**: 所有 `{xxx}` 占位符必须原样保留
2. **描述越具体效果越好**: 包含颜色、线条、光影、构图等具体要求
3. **负面提示词很重要**: 始终包含负面提示词来排除不需要的内容
4. **先小批量测试**: 建议先用 1-2 张图测试 prompt 效果
